# Click Battle

A competitive two-player tapping game built with Flutter. Challenge your friends or play against AI in this fast-paced clicking battle!

## Features

- 🎮 Two game modes:
  - Single Player (vs AI)
  - Two Players (vs Friend)
- ⏱️ Time Attack mode: Race against time to score the most points
- 🎯 Score Target mode: First to reach the target score wins
- 🤖 Three AI difficulty levels:
  - Easy
  - Normal
  - Hard
- 🎵 Background music and sound effects
- 🌐 Multi-language support
- 🎨 Modern and responsive UI
- 📱 Cross-platform support (iOS, Android, Web)

## Getting Started

### Prerequisites

- Flutter SDK (>=3.0.0)
- Dart SDK (>=3.0.0)
- Android Studio / VS Code with Flutter extensions

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/clickbattle.git
```

2. Navigate to the project directory:
```bash
cd clickbattle
```

3. Install dependencies:
```bash
flutter pub get
```

4. Run the app:
```bash
flutter run
```

## Development

- Just Audio for sound effects
